Quick Start

From a one-line install to a running CUDA kernel on CPU in minutes.

Fastest: install the prebuilt wheel (no toolchain)

Each GitHub Release ships a self-contained, LLVM-free wheel per platform (Linux / macOS / Windows). It bundles the native engine, so you need nothing but Python 3.8+ and NumPy — no compiler, no CUDA, no GPU:

bash
# Use a virtual environment (modern Debian/Ubuntu block pip into the
# system Python — PEP 668 'externally-managed'):
python3 -m venv ~/.venvs/vgre && source ~/.venvs/vgre/bin/activate
pip install numpy
pip install vgre-0.1.0-py3-none-linux_x86_64.whl   # or -macosx_* / -win_amd64

python -c "import vgre; print('native:', vgre.NATIVE_AVAILABLE)"
Tip

Releases: github.com/etienne0114/vgre/releases. The wheel runs CUDA-C kernels and trains/serves the in-tree transformer LM entirely on CPU.

Build from source (Linux / macOS)

bash
git clone https://github.com/etienne0114/vgre.git
cd vgre
bash install_local.sh

install_local.sh detects and installs missing dependencies (CMake, LLVM, OpenMP, Flutter), builds the native engine and dashboard, writes ~/.vgre/env, creates your auth token, and links the CLI tools into ~/.local/bin.

Open a new terminal, then:

bash
vgre-dashboard          # launch the real-time monitor
vgre-start --test       # local master + worker self-test

Run a CUDA program

Build your CUDA source as usual, then run it against the VGRE runtime shim instead of the NVIDIA driver:

bash
# Linux — preload the CUDA-runtime shim
LD_PRELOAD=$VGRE_INSTALL_DIR/lib/libvgre_cudart.so ./my_cuda_app

# macOS
DYLD_INSERT_LIBRARIES=$VGRE_INSTALL_DIR/lib/libvgre_cudart.dylib ./my_cuda_app
Tip

No source changes are needed. VGRE implements ~95% of the commonly used CUDA Runtime and Driver APIs; unsupported calls return a clear error rather than silently misbehaving.

Try the local language model

python
import vgre
tok = vgre.Tokenizer().train(open('corpus.txt').read(), num_merges=512)
lm  = vgre.LanguageModel(vocab=tok.vocab_size, n_layer=4, d_model=256, n_head=4)
# ... train, then:
print(tok.decode(lm.generate(tok.encode('Once upon a time'), n_new=40)))
