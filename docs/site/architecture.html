Architecture

How the pieces fit together.

Layers

  1. Interception — CUDA/OpenCL API shims capture calls at load time.
  2. Compilation — Clang AST → LLVM IR → ORC JIT native code, with a persistent disk+memory cache.
  3. Execution — OpenMP thread pool + AVX2/AVX-512 SIMD; block/warp scheduling and shared-memory emulation.
  4. Memory — UVM via an OS page-fault handler; stream-ordered pools; LZ4-compressed cluster transfers.
  5. Distribution — authenticated, encrypted TCP transport; NCCL-style + software-RDMA collectives; tensor/pipeline parallelism and a GSPMD auto-partitioner.
  6. ML stack — autograd, BLAS GEMM, tokenizer, samplers, LoRA, HNSW, checkpoint loaders (safetensors / GGUF).

Design principles

  • Real implementations only — no stubs, mocks, or placeholder math in shipped paths.
  • From-scratch primitives (JIT, tokenizer, vector index, crypto, collectives) to avoid vendor lock-in.
  • Warnings-as-errors, and a 300-test suite gating every change on Linux.
