Environment Variables

Written to ~/.vgre/env by install_local.sh and loaded automatically. On Windows they are set in User scope by vgre_sync.bat / vgre_env.ps1.

Core

VariableDefaultDescription
VGRE_LIB_PATHautoAbsolute path to libvgre.so / vgre.dll.
LD_LIBRARY_PATHextendedDirectory containing the VGRE shared libraries.
VGRE_LOG_LEVELINFOVerbosity: DEBUG | INFO | WARN | ERROR.
VGRE_INSTALL_DIR~/.local/share/VGREInstallation directory.

Execution backend

VariableDefaultDescription
VGRE_EXEC_BACKENDautoExecution tier: interp (PTX interpreter), cp (compiled-fiber), or ssa (Tier-2 SSA). Unset = fastest tier that accepts the kernel.
VGRE_DISABLE_NATIVE0Set to 1 to skip the native x86-64 JIT and use the compiled tier.
VGRE_SSA_ARM_NATIVEonNative AArch64 codegen for the SSA backend is on by default; set to 0 to force the portable evaluator.
VGRE_IPC_MODEOFFMPS-style IPC multiplexing (ON shares one runtime across processes).

Cluster / networking

VariableDefaultDescription
VGRE_PORT7777TCP port for master and worker nodes.
VGRE_CLUSTER_MASTER_ADDRESS—WAN direct connect: IP:PORT, hostname, or [::1]:PORT.
VGRE_CLUSTER_ADVERTISED_ADDRESS—Master public address embedded in UDP pings (NAT).
VGRE_CLUSTER_NODES—Comma-separated worker IP:PORT list (master side).
VGRE_MESH_PEERS—Comma-separated peer list for full-mesh topology.
VGRE_CLUSTER_DISCOVERYenabledSet to OFF for pure WAN / explicit-address mode.
VGRE_TCP_AUTH_TOKEN_FILE~/.vgre/tokenPath to the shared cluster auth token file.
VGRE_TCP_AUTH_TOKEN—Raw token string (prefer the file).

WAN / connection tuning

VariableDefaultDescription
VGRE_CLUSTER_CONNECT_TIMEOUT_SEC10TCP connect timeout, seconds (1–120).
VGRE_CLUSTER_MAX_BACKOFF_SEC120Maximum reconnection retry interval (10–3600).
VGRE_CLUSTER_IDLE_EVICT_SEC300Silence before an idle connection is evicted (0 = off).

Discovery

VariableDefaultDescription
VGRE_DISCOVERY_BUCKET_IDautokvdb.io bucket ID for cross-LAN token-keyed discovery.
VGRE_CLUSTER_UDP_ANNOUNCE_PORT7778UDP port the master broadcasts on (must match on all nodes).
VGRE_CLUSTER_UDP_WORKER_PORT7779UDP port workers broadcast on (must match on all nodes).

GPU cache model

VariableDefaultDescription
VGRE_L1_CACHE_KB32Per-block L1 cache (16 | 32 | 64 | 128).
VGRE_L2_CACHE_MB6Per-device L2 cache (2 | 6 | 20 | 40).

Performance tuning

VariableDefaultDescription
VGRE_ENABLE_NUMA0NUMA-aware thread scheduling (Linux).
VGRE_WORKER_THREADSauto (nproc)Override the worker thread count.
VGRE_SIMD_LEVELautoForce SSE4 | AVX | AVX2 | AVX512.

Configuration management

VariableDefaultDescription
VGRE_CONFIG_FILE—Path to a JSON or YAML config file; loads its variables when set.
VGRE_CONFIG_HOT_RELOADfalseWatch the config file and hot-reload on change.
VGRE_DEPLOYMENT_PROFILEdevelopmentProfile: development | staging | production | custom.

Kubernetes / container

VariableDefaultDescription
VGRE_DEVICE_PLUGIN_PATH/var/lib/kubelet/device-plugins/kubelet.sockOverride the kubelet socket for K8s device-plugin registration.
Tip

Every variable is optional — unset ones fall back to the defaults above.
