Environment Variables

Written to ~/.vgre/env by the installer and loaded automatically.

Core

VariableDefaultDescription
VGRE_LIB_PATHautoAbsolute path to the shared library.
VGRE_LOG_LEVELINFODEBUG | INFO | WARN | ERROR.
VGRE_INSTALL_DIR~/.local/share/VGREInstallation directory.
VGRE_WORKER_THREADSnprocOverride worker thread count.
VGRE_SIMD_LEVELautoForce SSE4 | AVX | AVX2 | AVX512.
VGRE_ENABLE_NUMA0NUMA-aware scheduling (Linux).

Cluster / networking

VariableDefaultDescription
VGRE_PORT7777TCP port for master and workers.
VGRE_CLUSTER_MASTER_ADDRESS—WAN direct connect (IP:PORT / host / [::1]:PORT).
VGRE_CLUSTER_ADVERTISED_ADDRESS—Master public address in UDP pings (NAT).
VGRE_CLUSTER_NODES—Comma-separated worker IP:PORT list (master).
VGRE_TCP_AUTH_TOKEN_FILE~/.vgre/tokenShared cluster auth token file.
VGRE_CLUSTER_CONNECT_TIMEOUT_SEC10TCP connect timeout (1–120).

GPU cache model

VariableDefaultDescription
VGRE_L1_CACHE_KB32Per-block L1 cache (16 | 32 | 64 | 128).
VGRE_L2_CACHE_MB6Per-device L2 cache (2 | 6 | 20 | 40).
Note

On Windows these are set in User scope by vgre_sync.bat / vgre_env.ps1. The full list lives in docs/USER_GUIDE.md §5.
