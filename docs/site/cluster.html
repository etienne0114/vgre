Distributed Clusters

Scale kernels across machines over LAN or WAN.

Token setup

Every node in a cluster shares one auth token. Generate it on the master and distribute it to workers:

# On the MASTER
vgre-token generate            # writes ~/.vgre/token, prints SHA-256 fingerprint

# On every WORKER (choose one)
scp master:~/.vgre/token ~/.vgre/token
vgre-token set <paste-token-here>

# Verify both sides match
vgre-token fingerprint

Start the cluster

# Master (LAN auto-discovery on)
vgre-start --master

# Workers on the same LAN
vgre-start --worker

# Workers over WAN (explicit master address)
vgre-start --worker --master-address 78.45.12.99:7777

WAN connectivity

For NAT traversal, the master advertises its public address in UDP pings. vgre-discover finds your public IP and registers it:

vgre-discover --set-master     # master: publish public IP
vgre-discover --register       # cross-LAN token-keyed discovery

Channels are authenticated with HMAC-SHA256 and encrypted with AES-256-CTR; transfers use LZ4 compression. Tuning knobs are in Environment Variables.
