API Reference

The core surface for training and running language models, plus the vgre.nn framework for building arbitrary networks. Signatures below match the shipped bindings.

vgre.LanguageModel

An in-tree Llama-style decoder LM (RMSNorm, RoPE, causal attention, SwiGLU FFN).

lm = vgre.LanguageModel(
    vocab,               # vocabulary size (required)
    n_layer=4,
    d_model=256,         # must be divisible by n_head; head_dim must be even
    n_head=8,
    d_ff=0,              # 0 → default (SwiGLU inner size derived from d_model)
    max_seq=256,
    dropout=0.0,
    tie_embeddings=False,
    seed=1234,
)

Properties & training

MemberDescription
num_parametersTotal parameter count (int).
train_step(ids, targets, lr=3e-3)One AdamW step over a single sequence; ids and targets are equal-length token lists. Returns the loss (float).
train_batch(batch, lr, clip=1.0)Accumulate gradients over a batch of (ids, targets) pairs, then one clipped optimizer step. Returns mean batch loss. More stable than train_step.
loss(ids, targets)Forward-only cross-entropy (no gradient step) — for validation.

Generation

lm.generate(
    prompt,                  # list[int] token ids
    n_new=32,
    temperature=0.0,         # <=0 → greedy
    top_k=0,                 # >0 → keep top-k logits
    top_p=1.0,               # <1 → nucleus (cumulative-probability) sampling
    repetition_penalty=1.0,  # >1 → discourage repeats
    seed=0,
) -> list[int]               # returns prompt + newly generated tokens

Quantized inference & KV cache

These affect generation only; training stays fp32.

MethodDescription
set_bf16_inference(on=True)Run generation on bf16-cached weights (half the matmul-weight footprint, fp32 accumulation).
set_int8_inference(on=True)Weight-only int8 (~4× smaller, per-channel scale). Mutually exclusive with bf16.
set_int8_kv_cache(on=True)Store the KV cache as int8 (per-(position, head) absmax scale). Greedy-identical on tested models.
set_int4_kv_cache(on=True)4-bit packed KV cache (further ~2× over int8). A memory/quality tradeoff; takes precedence over int8.
drop_fp32_weights()Free the fp32 master weights after enabling bf16/int8 inference. Serve-only afterwards (no more training).

Persistence

lm.save(path)Write the model to disk.
lm.load(path)Load weights (the constructor config must match the checkpoint).

vgre.Tokenizer

A from-scratch byte-level BPE tokenizer, trainable on any text or loadable from Hugging Face files.

MemberDescription
train(corpus, num_merges=512)Train BPE merges on a string. Returns self.
load_hf(tokenizer_json_path)Load a Hugging Face tokenizer.json (GPT-2, Llama-3, Qwen, Phi, …), including special tokens.
load_gpt2(vocab_json, merges_txt)Load the two-file GPT-2 tokenizer form.
encode(text) / decode(ids)Text ⇄ token ids.
vocab_sizeVocabulary size (int).
special_id(content)Id of a special token (e.g. '<|im_end|>'); -1 if absent.

vgre.cosine_lr(step, warmup, total, base_lr, min_lr=0.0)

Cosine learning-rate schedule with linear warmup — matches the C++ trainer. Returns a float.

vgre.nn — autograd framework

A small PyTorch-like framework: reverse-mode autodiff over VGRE's CPU engine, with tensors, functional ops, layer modules, and optimizers. No GPU, no external ML library.

import numpy as np, vgre.nn as nn

W = nn.tensor(np.random.randn(4, 3) * 0.1, requires_grad=True)
b = nn.tensor(np.zeros(3), requires_grad=True)
opt = nn.AdamW([W, b], lr=1e-2)

for step in range(200):
    opt.zero_grad()
    logits = nn.matmul(x, W) + b                 # x: nn.Tensor [N,4]
    loss = nn.softmax_cross_entropy(logits, targets)
    loss.backward()
    opt.step()

Tensor

nn.tensor(data, requires_grad=False) wraps a NumPy array. A Tensor has .shape, .size, .numpy(), .grad(), .set_(data), .item(), and .backward(). Operators @ (matmul), +, and * are overloaded.

Functional ops

  • Linear algebra: matmul, bmm, linear_tied, add, mul, scale, transpose, reshape, concat.
  • Activations: relu, gelu, silu, sigmoid, tanh, exp, softplus, softmax, mean, dropout.
  • Norms & embed: layer_norm, rms_norm, embedding, index_select, index_add.
  • Attention & sequence: rope, attention, flash_attention, selective_scan (Mamba/SSM recurrence).
  • Vision: conv2d, max_pool2d, avg_pool2d, batch_norm2d.
  • Losses: softmax_cross_entropy, softmax_cross_entropy_soft, distillation_loss, mtp_loss.
  • Quantization-aware: ternary_quantize (BitNet b1.58 STE), structured_nm_mask / structured_nm_metadata (N:M sparsity).
  • Memory & distributed: checkpoint (gradient checkpointing), all_reduce, all_reduce_gradients, world_size.

Layer modules

Subclasses of nn.Module (with .parameters(), .named_parameters(), .train()/.eval()):

  • Core: Linear, Embedding, LayerNorm, RMSNorm, Dropout, Sequential, ReLU, Flatten.
  • Vision: Conv2d, BatchNorm2d, MaxPool2d, AvgPool2d.
  • Transformer & sequence: MultiHeadAttention, TransformerBlock (optionally MoE), SSMBlock, MambaBlock, hybrid_blocks(...), MTPHeads.
  • Sparse / quantized / adapters: MoELayer, BitLinear (ternary), StructuredSparseLinear (N:M), LoRALinear, QLoRALinear.

Optimizers

nn.AdamW(params, lr=1e-3, weight_decay=0.01)
nn.SGD(params, lr=1e-2, momentum=0.0, weight_decay=0.0)
# opt.zero_grad(); loss.backward(); opt.step(clip=1.0); opt.set_lr(lr)

Generation helpers

  • greedy_generate(model, prompt, n_new)
  • speculative_generate(model, prompt, n_new, draft_fn, k=4) — lossless (greedy-identical) speculative decoding.
  • speculative_sample(target, draft, prompt, n_new, k, temperature, top_p, seed) — sampler-exact speculative decoding.
  • Drafters: ngram_draft_fn, model_draft_fn, mtp_draft_fn.

Checkpoint I/O

nn.save(model, path) / nn.load(model, path) use standard safetensors, loadable by VGRE's native SafeTensors reader.
