What VGRE needs to build and run — and the optional libraries that unlock extra features.

Tip

LLVM is optional. The zero-burden build (-DVGRE_ENABLE_JIT=OFF) needs nothing but a C++17 compiler and runs the full suite on the from-scratch four-tier CPU backend — see Installation.

Optional libraries — auto-detected

These activate silently when present at configure time; the build never fails for a missing optional dependency, it downgrades gracefully with a CMake warning.
