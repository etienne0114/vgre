The Dashboard

A real-time Flutter monitor for the running engine.

Launch with vgre-dashboard. It loads the native library in-process and polls live telemetry — no mock data. Pages:

PageWhat it shows
DashboardLive utilization gauges, workload throughput, UVM activity, log stream.
Kernel ExplorerJIT-compiled kernels, launch counts, occupancy, per-kernel timing.
Cluster TopologyConnected nodes, per-node load, network heatmap.
Hardware TuningToggle background compute, block-threads, profiler; set cache model.
Memory AnalysisAllocation map, bandwidth stats, UVM page residency.
SettingsPolling interval, database retention, connection config.

Documentation links

The dashboard's Help & Docs section opens this site directly in your browser — the Documentation, Quick Start, and API Reference items are wired to the pages here.

Tip

The connection badge distinguishes LIVE, DELAYED, and STALE so the UI never presents stale telemetry as current.
