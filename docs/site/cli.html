CLI Tools

The command-line utilities installed with VGRE.

CommandPurpose
vgre-dashboardLaunch the real-time Flutter monitor.
vgre-startStart a master or worker node (--master / --worker / --test).
vgre-tokenGenerate / set / fingerprint the shared cluster auth token.
vgre-discoverPublic-IP discovery and cross-LAN registration.
vgre_ptx_gdbserverServe a PTX kernel to a stock gdb for step debugging.
gpt2_inferReal GPT-2 inference from safetensors/GGUF (matches Hugging Face).

Examples

vgre-start --test                       # local self-test
vgre-token generate                     # new token + fingerprint
vgre-discover --set-master              # publish public IP
gpt2_infer model.safetensors --gen 'Hello'
