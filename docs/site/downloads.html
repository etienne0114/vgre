Downloads

Prebuilt, self-contained wheels — no compiler, no CUDA, no GPU.

Every GitHub Release ships a self-contained, LLVM-free wheel per platform. Each bundles the native engine, so you need only Python 3.8+ and NumPy. The wheels are built and smoke-tested (import + train a language model) on Linux, macOS and Windows runners in CI.

Latest release — v0.1.0

Pick your platform, download the wheel, then copy the pip install command (each block has a Copy button):

🐧 Linux x86-64

⬇ Download vgre-0.1.0-py3-none-linux_x86_64.whl

bash
pip install vgre-0.1.0-py3-none-linux_x86_64.whl

🍎 macOS (Apple Silicon)

⬇ Download vgre-0.1.0-py3-none-macosx_10_13_universal2.whl

bash
pip install vgre-0.1.0-py3-none-macosx_10_13_universal2.whl

🪟 Windows x86-64

⬇ Download vgre-0.1.0-py3-none-win_amd64.whl

bash
pip install vgre-0.1.0-py3-none-win_amd64.whl

Install straight from the release URL

No manual download — pip fetches the wheel for you. Install into a virtual environment: modern Debian/Ubuntu block pip into the system Python (PEP 668 “externally-managed”).

bash
python3 -m venv ~/.venvs/vgre && source ~/.venvs/vgre/bin/activate
pip install numpy
pip install https://github.com/etienne0114/vgre/releases/download/v0.1.0/vgre-0.1.0-py3-none-linux_x86_64.whl   # or -macosx_* / -win_amd64
python -c "import vgre; print('native:', vgre.NATIVE_AVAILABLE)"
Tip

The wheels are compiled at the universal x86-64 baseline, so they load on any x86-64 CPU; the hot kernels then detect the CPU at runtime and use AVX2 / AVX-512 automatically where present — one wheel, portable to a low-end laptop and fast on a server, no fixed ISA required.

Verify it works

The bundled native library runs CUDA-C kernels and trains/serves the in-tree transformer LM on CPU:

python
import vgre
tok = vgre.Tokenizer().train(open('corpus.txt').read(), num_merges=1024)
lm  = vgre.LanguageModel(vocab=tok.vocab_size, n_layer=6, d_model=256, n_head=8)
# lm.train_step(...) then lm.generate(...) — CPU only, no GPU/LLVM/BLAS.

Container image (GHCR)

A multi-arch (amd64/arm64) LLVM-free image is published on a tagged release:

bash
docker run --rm ghcr.io/etienne0114/vgre:0.1.0 --version

Build from source

Prefer to build your own? See the Installation guide — including the zero-burden LLVM-free build and bindings/python/build_wheel.sh to produce a wheel for your exact platform.

Warning

The macOS wheel is built on Apple Silicon (arm64). Intel-Mac (x86-64) users should build from source until an x86-64 macOS wheel is added to the release.
