Downloads

Prebuilt, self-contained wheels — no compiler, no CUDA, no GPU.

Every GitHub Release ships a self-contained, LLVM-free wheel per platform. Each bundles the native engine, so you need only Python 3.8+ and NumPy. The wheels are built and smoke-tested (import + train a language model) on Linux, macOS and Windows runners in CI.

Latest release — v0.1.0

PlatformWheelInstall
Linux x86-64vgre-0.1.0-…-linux_x86_64.whlpip install vgre-0.1.0-py3-none-linux_x86_64.whl
macOS (Apple Silicon)vgre-0.1.0-…-macosx_universal2.whlpip install vgre-0.1.0-py3-none-macosx_10_13_universal2.whl
Windows x86-64vgre-0.1.0-…-win_amd64.whlpip install vgre-0.1.0-py3-none-win_amd64.whl
Tip

Install straight from the release URL without downloading first:

pip install https://github.com/etienne0114/vgre/releases/download/v0.1.0/vgre-0.1.0-py3-none-linux_x86_64.whl
python -c "import vgre; print('native:', vgre.NATIVE_AVAILABLE)"

Verify it works

The bundled native library runs CUDA-C kernels and trains/serves the in-tree transformer LM on CPU:

import vgre
tok = vgre.Tokenizer().train(open('corpus.txt').read(), num_merges=1024)
lm  = vgre.LanguageModel(vocab=tok.vocab_size, n_layer=6, d_model=256, n_head=8)
# lm.train_step(...) then lm.generate(...) — CPU only, no GPU/LLVM/BLAS.

Container image (GHCR)

A multi-arch (amd64/arm64) LLVM-free image is published on a tagged release:

docker run --rm ghcr.io/etienne0114/vgre:0.1.0 --version

Build from source

Prefer to build your own? See the Installation guide — including the zero-burden LLVM-free build and bindings/python/build_wheel.sh to produce a wheel for your exact platform.

Warning

The macOS wheel is built on Apple Silicon (arm64). Intel-Mac (x86-64) users should build from source until an x86-64 macOS wheel is added to the release.
