Local AI: LoRA · RAG · LM

A complete offline machine-learning stack built into the runtime — no PyTorch, no FAISS, no external tokenizer library.

LoRA fine-tuning

vgre.nn.LoRALinear adds trainable low-rank adapters over a frozen base weight, so you can fine-tune on a CPU/laptop with a fraction of the parameters. Adapters merge back to the base for zero-overhead inference.

from vgre import nn
layer = nn.LoRALinear.from_linear(pretrained, r=8, alpha=16)
opt   = nn.AdamW(layer.adapter_parameters(), lr=1e-3)   # trains A,B only
# ... training loop ...
layer.merge()                 # fold adapter into W for fast inference
layer.save_adapter('style.npz')   # kilobytes, not the whole model

Vector search (HNSW)

vgre.vector.VectorIndex is a from-scratch Malkov–Yashunin HNSW index — cosine or L2, binary save/load, recall@10 ≈ 0.99 vs brute force.

import numpy as np
from vgre.vector import VectorIndex
ix = VectorIndex(dim=64, metric='cosine')
ix.add(embeddings, ids=np.arange(len(embeddings)))
ids, dists = ix.search(query_vec, k=10)
ix.save('docs.vgvx')

Tokenizer + language model

Load any modern Hugging Face tokenizer.json (GPT-2, Llama-3, Qwen, Phi, DeepSeek) and get that model's exact token ids — verified token-for-token against the real HF tokenizers library.

import vgre
tok = vgre.Tokenizer().load_hf('tokenizer.json')
ids = tok.encode('Hello, world!')
assert tok.decode(ids) == 'Hello, world!'
Tip

Together these complete a fully local embed → index → retrieve → generate → fine-tune RAG loop that never touches the network.
