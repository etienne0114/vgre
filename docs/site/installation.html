Installation

Manual build steps and platform notes.

Tip

The quickest way to get running is the prebuilt wheel — see Downloads. Build from source when you want the dashboard, the cluster tools, or to hack on the engine.

Prerequisites

Linux (Ubuntu / Debian)

bash
# Full build (with the optional LLVM JIT):
sudo apt install -y cmake ninja-build clang llvm-18-dev \
    libomp-dev libssl-dev libsqlite3-dev libkeyutils-dev zlib1g-dev

# LLVM-free build needs no llvm-18-dev / libomp-dev — just clang + the above.

macOS (Homebrew — paths discovered automatically at configure time)

bash
brew install cmake llvm@18 libomp ninja sqlite lapack
# LLVM-free build needs only:  brew install cmake ninja sqlite

Windows (PowerShell, VS 2022 present)

powershell
# One-shot: installs LLVM 18 + Ninja + CMake and configures the build.
powershell -ExecutionPolicy Bypass -File scripts\Install-BuildTools.ps1
powershell -ExecutionPolicy Bypass -File scripts\Install-VGRETools.ps1

# Or by hand with Chocolatey:
choco install -y llvm ninja sqlite cmake

Flutter (optional — only for the dashboard)

bash
sudo snap install flutter --classic     # Linux
brew install --cask flutter              # macOS
choco install flutter                    # Windows

Build — Linux / macOS (full, with LLVM JIT)

bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
ctest --test-dir build -j$(nproc)     # full suite: 399/399 on Linux

Build — Windows (clang-cl + Ninja)

Windows builds LLVM-free-friendly with clang-cl; the full suite is green in CI on windows-2022. From a Developer PowerShell for VS 2022:

powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release `
  -DCMAKE_C_COMPILER=clang-cl -DCMAKE_CXX_COMPILER=clang-cl `
  -DVGRE_ENABLE_OPENMP=OFF -DVGRE_WARNINGS_AS_ERRORS=OFF
cmake --build build --parallel
ctest --test-dir build --output-on-failure

Zero-burden build (no LLVM, no OpenMP)

VGRE does not need LLVM to execute kernels — a from-scratch CUDA-C front-end feeds a four-tier CPU backend (PTX interpreter, compiled-fiber tier, native x86-64 JIT, and an optional SSA optimizing backend). Build with only a C++17 compiler:

bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
    -DVGRE_ENABLE_JIT=OFF -DVGRE_ENABLE_OPENMP=OFF
cmake --build build -j$(nproc)
ctest --test-dir build -j$(nproc)     # LLVM-free suite: 379/379

Build the Python wheel

bash
bash bindings/python/build_wheel.sh build   # → bindings/python/dist/*.whl
pip install bindings/python/dist/vgre-*.whl
